# DC Theme

DC Theme is a Joomla 6 site template with eight content modules. Branding, colours, fonts, header layout, region widths and section order are all set in the template style in Joomla admin.

## What Is in the Package

One package, `pkg_dctheme`, installs 11 extensions:

| Extension | Type | Purpose |
|-----------|------|---------|
| DC Theme | Template | The site template – see [Branding](/dctheme/template/branding) and the other Template pages |
| DC Theme - Hero Banner | Module | Headline band with a picture, video, another module or nothing beside the words – see [Hero Banner](/dctheme/modules/hero) |
| DC Theme - Section | Module | Full-width band with a heading, background and column grid – see [Section](/dctheme/modules/section) |
| DC Theme - Pricing | Module | Price table, one card per plan, formatted for the currency – see [Pricing](/dctheme/modules/pricing) |
| DC Theme - Menu | Module | Horizontal, vertical and inline menus with mega panels – see [Menu](/dctheme/modules/menu) |
| DC Theme - Testimonials | Module | Customer quotes as a grid, a carousel or a scrolling row – see [Testimonials](/dctheme/modules/testimonials) |
| DC Theme - Gallery | Module | Photos as a grid or a slider, with a lightbox – see [Gallery](/dctheme/modules/gallery) |
| DC Theme - FAQ | Module | Accordion of questions with FAQ structured data – see [FAQ](/dctheme/modules/faq) |
| DC Theme - Logo Strip | Module | Partner, client or accreditation logos as a row or a scrolling row – see [Logo Strip](/dctheme/modules/logo-strip) |
| System - DC Theme | Plugin | Holds your license key so Joomla can install updates. It changes nothing on the site |
| Sample Data - DC Theme | Plugin | Adds a one-click example site to Joomla's Sample Data panel – see [Sample Data](/dctheme/getting-started/sample-data) |

## Features

- **Colour** – Ten ready-made palettes checked for contrast in light and dark, or your own four colours with automatic contrast correction. Light, dark or follow the visitor's device, with an optional switch for visitors.
- **Type** – Self-hosted fonts, with the download size shown beside each choice. One setting scales every text size, another sets heading size.
- **Header** – Four layouts, three behaviours on scroll, a top bar and a mobile menu panel.
- **Layout** – 25 module positions, per-screen visibility for every region, region widths, and drag-to-reorder bands above the content.
- **Consent and Analytics** – Google Analytics, Google tag, Tag Manager, Google Ads and Meta pixel, held back until the visitor agrees, with a built-in consent bar.
- **Extras** – Back to top, floating WhatsApp button, social profile icons, reveal on scroll and a `user.css` that survives updates.
- **Core Overrides** – Article, category blog, featured, contact, login, registration, profile and password reset pages are styled to match.
