# Contona Docs

Official documentation for [Contona](https://contona.com) Joomla extensions.

## Extensions

- **LicenseDock** – Sell digital products and software licenses with Joomla
- **DC Theme** – One Joomla template for every client site
- **DC Leads** – Lead capture forms with campaign tracking
- **Anything Slider** – Image sliders with animated elements and smooth transitions
