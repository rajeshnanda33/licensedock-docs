# General Settings

**Components → DC Leads → Settings** has four tabs:

| Tab | Covers |
|-----|--------|
| License | Your license key – see below |
| Email | Notifications, sender, auto-reply – see [Email Settings](/dcleads/settings/email) |
| Spam protection | Honeypot, captcha, timer – see [Spam Protection](/dcleads/settings/spam) |
| General | Default country, keeping data on uninstall – see below |

**Save** keeps you on the page, **Save & Close** returns to the Dashboard.

## License Tab

Needed for updates. Forms work without it.

| Setting | Default | Description |
|---------|---------|-------------|
| License key | – | Your DC Leads key from your account. Checked against the store when saved |

The **Status** line under the field shows the current state of the key. See [Activate Your License](/dcleads/getting-started/installation#activate-your-license) for each status.

## General Tab

| Setting | Default | Description |
|---------|---------|-------------|
| Default country | None | Preselected in phone and country fields. **None**: phone fields use the country from the visitor's browser language, and country fields start empty |
| Keep leads when uninstalling | Yes | **No**: uninstalling deletes all forms and leads |

## Permissions

The **Permissions** toolbar button opens Joomla's permissions screen for DC Leads. It holds permissions only; every other setting is on the Settings screen.

Saving Permissions leaves your settings untouched while the **System - DC Leads campaign capture** plugin is enabled. With the plugin off, saving Permissions resets the Settings. See [Permissions](/dcleads/leads/#permissions) for what each action allows.
